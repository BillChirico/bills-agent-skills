# Volvox Brand

Brand guidance skill for Volvox LLC, Volvox.Bot, Decision Jar, Sobers, and Volvox Community visual and written assets.

## When to Use

- Creating Volvox-branded pages, posts, presentations, or UI
- Applying Volvox colors, typography, and logo assets
- Writing copy for Volvox.Bot, Decision Jar, Sobers, or Volvox Community
- Checking tone against the official Volvox voice

## Folder Contents

- `SKILL.md` - Core brand identity, colors, typography, tone, and resource map.
- `assets/` - Logo and marketing image assets.
- `references/app-store-guidelines.md` - Store listing, screenshot, keyword, and submission guidance.
- `references/press-kit.md` - Company boilerplate, founder bio, and media-ready details.
- `references/product-info.md` - Product links, positioning, pricing, and feature notes.
- `references/voice-guide.md` - Expanded voice and tone examples.

## Usage

Use this skill whenever an artifact should feel like Volvox, not generic SaaS wallpaper. Pull only the reference file that matches the task, then apply the brand system directly to the output.
